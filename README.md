##Analisis de Ventas

## Integrante
Leiva Francisco

## Escenario
Análisis de Ventas de una Pequeña Empresa.

## Descripción
Este proyecto analiza un conjunto de datos de ventas para obtener indicadores como ventas totales, prodSucto más vendido y evolución de ventas.

## Dataset
Se utilizó un archivo CSV con información de productos, cantidades vendidas, precios y fechas de venta.

scripts/
resultados/

## Ejecución

Ejecutar:

python scripts/analisis_ventas.py
